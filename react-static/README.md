# Static React replica

A standalone Vite/React static application for Markaz Al Murtaza Al Islami & Safia Islamic Institute.

- Includes the landing experience, programs, portfolio, donation details, SEO course pages and 30-language selector.
- Intentionally excludes the Hadith library and Next.js blog.
- Uses hash routes so it can be deployed on any static file host without rewrite configuration.

Run `npm install`, then `npm run dev` or `npm run build`.
